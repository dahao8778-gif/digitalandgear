# 2026-08-08 工作日志

## 修复 Search Console "网页会自动重定向" 警告
- 用户在 Cloudflare Pages 上线前检查时，Google Search Console 报告 6 个 URL 重定向问题：
  - http://digitalandgear.com/ (HTTP)
  - http://www.digitalandgear.com/ (HTTP+www)
  - https://www.digitalandgear.com/index.html (www)
  - https://digitalandgear.com/index.html (/index.html)
  - 2 个正常页面（bedroom 指南、LEVOIT 评测）也被列入，可能是 Google 通过其他 URL 变体跟过来的

### 诊断
- 项目源码完全正确：canonical/sitemap/站内链接全部指向 https://digitalandgear.com (非www)
- 根因：项目根目录缺少部署平台的重定向配置文件
- 解决方案：在根目录创建 _redirects (Cloudflare Pages 原生支持)

### 创建的文件
- `E:\网站\digitalandgear.com\_redirects` — 包含 4 条 301 规则：
  1. http://digitalandgear.com/* → https://digitalandgear.com/:splat
  2. http://www.digitalandgear.com/* → https://digitalandgear.com/:splat
  3. https://www.digitalandgear.com/* → https://digitalandgear.com/:splat
  4. /index.html → /

### 部署平台
- Cloudflare Pages（用户确认）
